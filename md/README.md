## Sobre o projeto

**Solução para o desafio QR Code Component do Frontend Mentor, desenvolvida durante o curso de Full Stack.**

*O objetivo era construir, a partir de um layout de referência do Figma, um card simples exibindo um QR code, título e descrição, centralizado na tela.*

Link do desafio: https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H
Frontend Mentor: QR code component challenge hub

Tecnologias utilizadas

-HTML5 semântico
-CSS3
-Variáveis CSS (:root) para cores e tipografia
-Flexbox e CSS Grid para centralização
-box-sizing: border-box
**O que foi feito**

  Estruturação do card (.card) com imagem, título e texto
  Uso de variáveis CSS para padronizar cores (--white, --slate-300, --slate-500, --slate-900) e fontes (--title-bold, --title-regular)
  Centralização do texto interno do card com display: flex e flex-direction: column
  Centralização do card
